\# Student Attendance Management System



\## About the Project

This is a beginner-friendly Java console-based project used to manage student attendance.



\## Features

\- Add student details

\- View student details

\- Mark students as present or absent

\- View attendance reports

\- Calculate attendance percentage



\## Technologies Used

\- Java

\- Git

\- GitHub



\## Purpose

The main purpose of this project is to learn Java programming and understand Git and GitHub version control.
